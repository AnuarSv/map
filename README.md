# GeoKZ (WaterMap Refactor)

Образовательная платформа для изучения географии Казахстана. Проект прошел глубокий рефакторинг для улучшения пользовательского опыта, производительности и визуального стиля.

## 🚀 Достигнутые результаты

### 1. Архитектура и Дизайн
*   **Современный стек**: Переход на React + Vite + TypeScript. Использование TailwindCSS для стилизации.
*   **Professional UI**: Полностью переработан интерфейс в стиле "Senior Frontend". Цветовая палитра изменена с градиентов на строгие и приятные глазу природные цвета (Emerald/Slate), что придает проекту вид серьезного образовательного продукта.
*   **Оптимизация**: Внедрен рендеринг карт через Canvas (`preferCanvas={true}`) для плавной работы с большими наборами данных GeoJSON.

### 2. Функционал
*   **Конструктор обучения**: Разработана гибкая система выбора тем для тестирования. Пользователь может сам выбирать категории (Области, Города, Реки, Рельеф) через "Конструктор" на главной странице.
*   **Интерактивный Квиз-плеер**:
    *   Визуальная обратная связь (зеленый/красный маркеры).
    *   Таймер и подсчет очков.
    *   Красивые анимированные переходы и результаты.
*   **Контурные карты**: Реализован режим "Контурной карты" с инструментами для рисования (полигоны, маркеры, подписи) и возможностью включить/отключить подсказки границ.
*   **Интерактивная карта**: Публичная карта для свободного изучения объектов с фильтрацией слоев.

### 3. Данные (Data)
*   **Очистка данных**: Проведен тщательный анализ и фильтрация исходных данных.
    *   Оставлены только ключевые реки (13 объектов) и озера (24 объекта) согласно учебным требованиям.
    *   Удален "визуальный шум" (мелкие ручьи, безымянные озера).
*   **Интеграция GeoJSON**: Данные регионов, городов и полезных ископаемых теперь загружаются локально и оптимизированы для веба.

## ⚙️ Запуск проекта

```bash
# Запуск всех сервисов в фоновом режиме
docker compose up -d

# Пересборка фронтенда (при изменениях кода)
docker compose up -d --build frontend
```

Приложение доступно по адресу: http://localhost:8080
